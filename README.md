# camouflage-to-canvas
Camouflage to Canvas website

A static site (plain HTML + CSS, no build step) built from the "Soft Unfettered" website redesign.

| Page | File |
| --- | --- |
| Homepage | `index.html` |
| Private Events · Camouflaged Paintbrush | `private-events.html` |
| Organizations | `organizations.html` |
| Shop & Gift Cards | `shop.html` |
| About | `about.html` |
| Journal · Blog & Podcast | `journal.html` |

- `css/site.css` holds the shared base styles and the `--accent` call-to-action color.
- `images/` holds the logo and photography.
- Copy in `[BRACKETS]` (prices, dates, testimonials) is placeholder content to fill in.
- Forms are front-end only; connect them to a booking or email service before launch.

To preview locally, open `index.html` in a browser or run `python3 -m http.server`.
